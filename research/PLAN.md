# Source plan and implementation scope

Read in Chrome on 29 October 2026 from [Audit Evidence Agent: Hackathon Plan](https://audit-evidence-agent-hackathon-plan-fe7p.pages.grok.bot/).

The proposal is an agent that vouches a supplied ledger sample to invoices, purchase orders and goods received notes. Each reported result must link to a source crop. Muse Spark plans tests and extracts structured fields and bounding boxes; SAM 3.1 refines evidence regions; deterministic code performs arithmetic and comparisons; Muse Spark Open on Baseten independently rereads crops without receiving the ledger answer. Confidence below 0.8 triggers one retry then escalation. Notes use Muse Voice Transcribe. A hash-chained event log accompanies the working paper.

Core entities: ledger lines, documents, extracted fields, evidence crops, claims, verifications, notes and human review decisions. UI: ledger table, source viewer with overlays, crop gallery, agent trace, review queue, export. Stack: TypeScript, Express, React, local persistence and portable container. Synthetic dataset: 25 samples with amount transposition, VAT error, short delivery, missing approval and duplicate invoice. Deterministic evaluation must be clearly distinguished from live model evaluation.

Keys are not yet available. The implementation must provide an explicitly labeled offline fixture mode and real, separately configured API adapters. Never pretend fixture values are AI extraction, rectangle crops are SAM segmentation, or offline verification is an independent model. Never silently fall back from live to demo. Record current actual implementation dates and tools used; the source plan's proposed earlier first-commit date and Muse Code attribution are not facts about this build.
